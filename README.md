## 课程简介

ECE313 概率论与工程应用主要研究随机现象的数学理论及其在工程中的应用。本课程涵盖概率论的基础概念、随机变量、概率分布、期望与方差、极限定理等核心内容，为信号处理、通信系统、机器学习等工程领域提供必要的数学基础。

## 课程内容

本课程主要包含以下几个核心模块：

### 1. 概率论基础 (Foundations of Probability)

- 概率的定义与公理
- 条件概率与独立性
- 全概率公式与贝叶斯定理
- 组合概率与排列

### 2. 随机变量 (Random Variables)

- 离散型随机变量
- 连续型随机变量
- 概率质量函数(PMF)与概率密度函数(PDF)
- 累积分布函数(CDF)
- 常见概率分布

### 3. 多维随机变量 (Multiple Random Variables)

- 联合概率分布
- 边缘分布与条件分布
- 随机变量的独立性
- 协方差与相关系数

### 4. 数学期望 (Expectation)

- 期望与方差
- 条件期望
- 不等式（马尔可夫、切比雪夫等）

### 5. 极限定理 (Limit Theorems)

- 大数定律
- 中心极限定理
- 在工程中的应用

### 6. 随机过程基础 (Introduction to Random Processes)

- 泊松过程
